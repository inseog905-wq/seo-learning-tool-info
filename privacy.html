1. 운영자와 적용 범위

운영자는 GitHub 계정 inseog905-wq입니다. 이 방침은 개인용 SEO Learning Tool 데스크톱 프로그램과 해당 프로그램 안내 사이트에 적용됩니다. 문의는 문의 게시판을 이용할 수 있습니다. 게시판은 공개되어 있으므로 토큰, 비밀번호, 비공개 성과 자료를 게시하지 마세요.

2. 접근하는 정보와 목적

  • Google 계정 식별자와 확인된 이메일: 계정 구분, 중복 로그인 방지, 계정 표시
  • OAuth 액세스 토큰과 갱신 토큰: 사용자가 동의한 Google API 조회 및 예약 수집 인증
  • Search Console 사이트 주소와 권한: 수집 가능한 사이트 확인
  • 날짜별 클릭·노출·CTR·평균 순위, 검색어·페이지·국가·기기별 성과: 표, 비교, 분석 자료 제공
  • 사용자가 URL 검사를 실행한 경우 해당 URL의 색인 상태, 크롤링 정보 및 대표 URL: 상태 확인과 이력 보관
  • 기술 진단에 입력한 주소와 공개 페이지의 HTML 분석 결과: 제목·설명·canonical·사이트 파일 진단
  • 수집 시각, 오류와 실행 로그: 수집 상태 확인 및 문제 해결

3. 저장 위치와 보관

프로그램은 계정 정보와 인증 파일을 PC의 credentials 폴더에, 성과 DB·조회 기록·진단 결과·로그를 data 폴더에 저장합니다. 사용자가 내보낸 파일은 사용자가 선택한 위치에 저장됩니다. 운영자 서버에 자동 업로드하지 않습니다. 로컬 파일은 별도 암호화 기능이 없으므로 PC 사용자 계정과 파일 접근 권한으로 보호해야 합니다. 사용자가 삭제할 때까지 보관되며 백업·내보내기 파일은 따로 남을 수 있습니다.

4. 외부 통신과 공유

인증과 조회를 위해 Google에 통신하며 URL 검사 시 검사할 URL과 사이트 속성을 Google에 전송합니다. 기술 진단 시 입력된 사이트에 공개 페이지와 robots.txt·사이트맵 접근 요청을 보냅니다. 인증 정보나 성과 데이터를 광고 목적으로 판매·공유하거나 AI 모델 학습에 사용하는 기능은 없습니다. 사용자가 CSV 등을 직접 공유하면 수신자는 사용자가 결정합니다.

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 따릅니다.

5. 연결 해제와 삭제

프로그램의 계정 관리에서 연결 해제를 선택하면 해당 계정의 사용 중인 로컬 토큰을 삭제하고 이후 자동 수집에서 제외합니다. 과거 성과와 로컬 백업은 자동으로 삭제하지 않습니다. Google의 접근 권한은 Google 계정의 연결된 앱 관리에서 철회할 수 있습니다.

모든 로컬 자료를 지우려면 프로그램을 종료하고 Windows 예약 수집 작업을 중지한 뒤, 프로젝트의 credentials 및 data 폴더와 별도로 만든 백업·내보내기 파일을 삭제하세요. 계정 통합 과정에서 만든 인증 백업도 credentials 폴더에 포함됩니다. 삭제 전에 필요한 기록을 확인하세요.

6. 안내 사이트 호스팅

안내 페이지는 GitHub Pages로 제공될 예정입니다. 이 페이지에는 별도 방문 추적 스크립트나 광고를 넣지 않습니다. 호스팅 제공자인 GitHub는 보안과 서비스 운영을 위해 방문자의 IP 주소 등을 처리할 수 있습니다. GitHub 개인정보처리방침을 참고하세요. 이 안내 페이지에서 Google 계정 로그인이나 성과 업로드를 받지 않습니다.
