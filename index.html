SEO Learning Tool

여러 사이트의 검색 성과를 PC에서 확인하는 개인용 데스크톱 도구

SEO Learning Tool은 사용자가 접근 권한을 가진 Google Search Console 사이트의 성과를 조회하고, Windows 컴퓨터에 저장해 비교하는 프로그램입니다. 이 웹사이트는 프로그램의 기능과 데이터 처리 방식을 안내합니다.

주요 기능

  • Google 계정 연결과 계정별 사이트 목록 조회
  • 사이트별 클릭·노출·CTR·평균 순위 수집 및 날짜별 기록 확인
  • Windows 예약 실행을 통한 정기 수집
  • 주간 성과 비교와 검색어·페이지·국가·기기별 상세 조회
  • 공개 페이지의 제목·메타 설명·canonical 및 사이트 파일 기술 진단

Google 계정 연결

Google의 로그인·동의 화면에서 Search Console 읽기 권한과 계정 식별 권한을 요청합니다. 연결할 계정을 선택하고 동의한 경우에만 해당 계정의 자료를 조회합니다. 프로그램은 Google 비밀번호를 입력받거나 저장하지 않습니다.

데이터는 어디에 저장되나요?

로그인 토큰, 연결 계정 정보와 수집 결과는 프로그램을 실행하는 PC에 저장됩니다. 개발자 서버나 이 안내 사이트로 성과 데이터를 전송하는 기능은 없습니다. 자세한 보관·삭제 방법은 개인정보처리방침에서 확인할 수 있습니다.

이용 범위

본인 또는 관리 권한이 있는 사이트를 분석하는 개인용 도구입니다. Google의 색인 등록, 검색 순위 상승 또는 트래픽 증가를 보장하지 않습니다. Google 계정 연결은 읽기 전용이며 자동 색인 생성 요청이나 사이트 내용 수정은 수행하지 않습니다.
