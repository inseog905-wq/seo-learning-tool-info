프로그램은 Google Search Console 자료 조회, 로컬 저장, 성과 비교, 기술 진단 및 조회 결과 확인을 지원합니다. 자동 색인 생성 요청과 사이트 내용 자동 수정은 제공하지 않습니다. 현재 개인용 개발 단계로 별도 유료 구독이나 결제를 받지 않습니다.

사용자는 Google 동의 화면에서 접근 권한을 결정하며 연결 해제 또는 권한 철회를 할 수 있습니다. PC의 인증 파일과 성과 자료를 안전하게 관리하고, 내보내거나 공개하는 정보의 범위를 확인해야 합니다. 관련 법령과 Google API 이용 조건을 준수해야 합니다.

Google의 데이터 지연, 익명화, 집계 방식, API 할당량 또는 권한 변경에 따라 조회 결과가 제한될 수 있습니다. 상세 행의 합계는 사이트 전체 합계와 일치하지 않을 수 있습니다. 프로그램의 진단 결과는 검토 자료이며 검색 순위·색인·트래픽 성과를 보장하지 않습니다.

예약 수집에는 컴퓨터 전원, Windows 로그인, 인터넷 연결, 유효한 계정 권한이 필요합니다. 프로그램 및 외부 서비스의 오류로 수집이 지연·중단될 수 있습니다. 기능과 실행 조건은 개발 및 외부 API 변경에 따라 달라질 수 있습니다.
